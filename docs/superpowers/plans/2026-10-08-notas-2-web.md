# Notas — Plan 2: Web (login, interfaz de 3 columnas y configuración)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Web app usable de punta a punta: registro con código de invitación, login, vistas Bandeja/Hoy/7 días/Completadas/Papelera, listas, carpetas, etiquetas, detalle de tarea con subtareas, configuración de zona horaria.

**Architecture:** Next.js App Router. Las páginas son Server Components que leen con `src/core/*`; las mutaciones son Server Actions (`src/app/app/actions.ts`) que verifican la sesión, llaman al núcleo, devuelven `ActionResult` (errores de dominio como texto) y revalidan. Componentes interactivos son Client Components en `src/components/`. Sesiones propias en base (cookie httpOnly con token aleatorio, guardado hasheado). En desarrollo, sin `DATABASE_URL`, se usa PGlite en disco (`.data/pglite`), así no hace falta Docker.

**Tech Stack:** Next.js 15, React 19, Tailwind CSS 4, lucide-react, Drizzle 0.45, PGlite (dev), Vitest, Playwright.

**Spec:** `docs/superpowers/specs/2026-10-08-notas-design.md`

**Cambios respecto del spec (decididos al planificar):**
- En lugar de Auth.js se usan **sesiones propias** (tabla `sessions`). Es menos código, sin dependencia beta, y el Plan 3 (OAuth) necesita igual una pantalla de login propia.
- **Registro solo con código de invitación** (`INVITE_CODE` en el entorno). Sin código configurado, el registro queda deshabilitado. Evita que cualquiera en internet se cree una cuenta.
- Tema claro/oscuro según el sistema operativo (sin botón).
- Estilo visual propio (opción B): layout de TickTick, paleta y tipografía propias.

**Firmas del núcleo disponibles** (ya implementadas en Plan 1; verificar contra `src/core/*.ts` antes de usarlas):

```ts
import { createHash, randomBytes } from 'node:crypto';
import { and, eq, gt, lte } from 'drizzle-orm';
import { sessions } from '@/db/schema';
import type { DB } from '@/db/types';
import { getUser, type PublicUser } from './users';

export const SESSION_TTL_DAYS = 30;

function hashToken(token: string): string {
  return createHash('sha256').update(token).digest('hex');
}

/** Crea una sesión. El token solo se devuelve acá; en la base se guarda su hash. */
export async function createSession(
  db: DB, userId: string, now: Date = new Date(),
): Promise<{ token: string; expiresAt: Date }> {
  const token = randomBytes(32).toString('base64url');
  const expiresAt = new Date(now.getTime() + SESSION_TTL_DAYS * 24 * 60 * 60 * 1000);
  await db.insert(sessions).values({ userId, tokenHash: hashToken(token), expiresAt });
  return { token, expiresAt };
}

export async function getSessionUser(db: DB, token: string, now: Date = new Date()): Promise<PublicUser | null> {
  if (!token) return null;
  const [row] = await db
    .select({ userId: sessions.userId })
    .from(sessions)
    .where(and(eq(sessions.tokenHash, hashToken(token)), gt(sessions.expiresAt, now)));
  return row ? getUser(db, row.userId) : null;
}

export async function deleteSession(db: DB, token: string): Promise<void> {
  await db.delete(sessions).where(eq(sessions.tokenHash, hashToken(token)));
}

/** Borra sesiones vencidas de TODOS los usuarios. Solo para el job de mantenimiento. */
export async function purgeExpiredSessions(db: DB, now: Date = new Date()): Promise<number> {
  const deleted = await db.delete(sessions).where(lte(sessions.expiresAt, now)).returning({ id: sessions.id });
  return deleted.length;
}
```

```ts
import path from 'node:path';
import * as schema from './schema';
import type { DB } from './types';

const MIGRATIONS = path.join(process.cwd(), 'drizzle');

// Se cachea en globalThis para sobrevivir al hot reload de Next.js en desarrollo.
const globalForDb = globalThis as unknown as { __notasDb?: Promise<DB> };

/**
 * Conexión única a la base, con migraciones aplicadas.
 * - Con DATABASE_URL: PostgreSQL (producción).
 * - Sin DATABASE_URL en desarrollo: PGlite en disco (PGLITE_DIR o .data/pglite).
 */
export function getDb(): Promise<DB> {
  globalForDb.__notasDb ??= connect().catch((err) => {
    globalForDb.__notasDb = undefined;
    throw err;
  });
  return globalForDb.__notasDb;
}

async function connect(): Promise<DB> {
  const url = process.env.DATABASE_URL;
  if (url) {
    const { default: postgres } = await import('postgres');
    const { drizzle } = await import('drizzle-orm/postgres-js');
    const { migrate } = await import('drizzle-orm/postgres-js/migrator');
    const db = drizzle(postgres(url), { schema });
    await migrate(db, { migrationsFolder: MIGRATIONS });
    return db;
  }
  if (process.env.NODE_ENV === 'production') {
    throw new Error('DATABASE_URL no está configurada');
  }
  const { PGlite } = await import('@electric-sql/pglite');
  const { drizzle } = await import('drizzle-orm/pglite');
  const { migrate } = await import('drizzle-orm/pglite/migrator');
  const dir = process.env.PGLITE_DIR ?? path.join(process.cwd(), '.data', 'pglite');
  const db = drizzle(new PGlite(dir), { schema });
  await migrate(db, { migrationsFolder: MIGRATIONS });
  return db as unknown as DB;
}
```

```ts
/** Limitador de ventana fija en memoria. Suficiente para una sola instancia del servidor. */
export function createRateLimiter({ max, windowMs }: { max: number; windowMs: number }) {
  const hits = new Map<string, { count: number; resetAt: number }>();
  return {
    /** Registra un intento; devuelve false si se superó el límite. */
    check(key: string, now: number = Date.now()): boolean {
      const entry = hits.get(key);
      if (!entry || now >= entry.resetAt) {
        hits.set(key, { count: 1, resetAt: now + windowMs });
        return true;
      }
      entry.count += 1;
      return entry.count <= max;
    },
    reset(key: string): void {
      hits.delete(key);
    },
  };
}
```

```ts
export const DEFAULT_AFTER_LOGIN = '/app/today';

/** Devuelve la ruta solo si es interna (empieza con "/" y no con "//" ni "/\"). */
export function safeRedirect(value: unknown, fallback: string = DEFAULT_AFTER_LOGIN): string {
  if (typeof value !== 'string' || !value.startsWith('/')) return fallback;
  if (value.startsWith('//') || value.startsWith('/\\')) return fallback;
  return value;
}
```

```ts
import { NotFoundError, ValidationError } from '@/core/errors';

export type ActionResult<T = void> = { ok: true; data: T } | { ok: false; error: string };

const GENERIC_ERROR = 'Ocurrió un error inesperado. Probá de nuevo.';

// redirect() y notFound() de Next.js lanzan errores con estos "digest"; hay que dejarlos pasar.
function isNextControlFlow(err: unknown): boolean {
  const digest = (err as { digest?: unknown } | null)?.digest;
  return typeof digest === 'string'
    && (digest.startsWith('NEXT_REDIRECT') || digest.startsWith('NEXT_HTTP_ERROR_FALLBACK') || digest === 'NEXT_NOT_FOUND');
}

/** Ejecuta una acción y convierte errores de dominio en mensajes para el usuario. */
export async function runAction<T>(fn: () => Promise<T>): Promise<ActionResult<T>> {
  try {
    return { ok: true, data: await fn() };
  } catch (err) {
    if (isNextControlFlow(err)) throw err;
    if (err instanceof ValidationError || err instanceof NotFoundError) return { ok: false, error: err.message };
    console.error(err);
    return { ok: false, error: GENERIC_ERROR };
  }
}
```

```ts
import { dayOfWeek } from '@/core/dates';

const SHORT_DAYS = ['Dom', 'Lun', 'Mar', 'Mié', 'Jue', 'Vie', 'Sáb'];
const LONG_DAYS = ['Domingo', 'Lunes', 'Martes', 'Miércoles', 'Jueves', 'Viernes', 'Sábado'];

function daysBetween(from: string, to: string): number {
  return Math.round((Date.parse(`${to}T00:00:00Z`) - Date.parse(`${from}T00:00:00Z`)) / 86_400_000);
}

function dayMonth(iso: string): string {
  return `${iso.slice(8, 10)}/${iso.slice(5, 7)}`;
}

/** "Hoy", "Mañana", "Ayer", día corto si cae en los próximos 6 días, o dd/mm[/aaaa]. */
export function formatDueLabel(dueDate: string, today: string): string {
  const diff = daysBetween(today, dueDate);
  if (diff === 0) return 'Hoy';
  if (diff === 1) return 'Mañana';
  if (diff === -1) return 'Ayer';
  if (diff > 1 && diff < 7) return SHORT_DAYS[dayOfWeek(dueDate)];
  if (dueDate.slice(0, 4) !== today.slice(0, 4)) return `${dayMonth(dueDate)}/${dueDate.slice(0, 4)}`;
  return dayMonth(dueDate);
}

export interface TaskGroup<T> {
  key: string;
  label: string;
  tasks: T[];
}

/** Agrupa (manteniendo el orden recibido) en Vencidas, un grupo por día y Sin fecha. */
export function groupTasksByDate<T extends { dueDate: string | null }>(tasks: T[], today: string): TaskGroup<T>[] {
  const overdue: T[] = [];
  const byDay = new Map<string, T[]>();
  const undated: T[] = [];
  for (const task of tasks) {
    if (task.dueDate === null) undated.push(task);
    else if (task.dueDate < today) overdue.push(task);
    else byDay.set(task.dueDate, [...(byDay.get(task.dueDate) ?? []), task]);
  }
  const groups: TaskGroup<T>[] = [];
  if (overdue.length) groups.push({ key: 'overdue', label: 'Vencidas', tasks: overdue });
  for (const day of [...byDay.keys()].sort()) {
    const diff = daysBetween(today, day);
    const label = diff === 0 ? 'Hoy' : diff === 1 ? 'Mañana' : `${LONG_DAYS[dayOfWeek(day)]} ${dayMonth(day)}`;
    groups.push({ key: day, label, tasks: byDay.get(day)! });
  }
  if (undated.length) groups.push({ key: 'undated', label: 'Sin fecha', tasks: undated });
  return groups;
}
```

```ts
/** Usuario logueado o null. Se memoiza por request. */
export const getCurrentUser = cache(async (): Promise<PublicUser | null> => {
  const token = (await cookies()).get(SESSION_COOKIE)?.value;
  if (!token) return null;
  return getSessionUser(await getDb(), token);

/** Usuario logueado; si no hay sesión, redirige a /login. Usar en TODA página y acción privada. */
export async function requireUser(): Promise<PublicUser> {
  const user = await getCurrentUser();
  if (!user) redirect('/login');
  return user;
}

export async function startSession(userId: string): Promise<void> {
  const { token, expiresAt } = await createSession(await getDb(), userId);
  (await cookies()).set(SESSION_COOKIE, token, {
    httpOnly: true,
    secure: process.env.NODE_ENV === 'production',
    sameSite: 'lax',
    path: '/',
    expires: expiresAt,
  });
}

export async function endSession(): Promise<void> {
  const store = await cookies();
  const token = store.get(SESSION_COOKIE)?.value;
  if (token) await deleteSession(await getDb(), token);
  store.delete(SESSION_COOKIE);
}
```

```ts
'use server';

import { createHash, timingSafeEqual } from 'node:crypto';
import { headers } from 'next/headers';
import { redirect } from 'next/navigation';
import { createUser, verifyCredentials } from '@/core/users';
import { getDb } from '@/db';
import { runAction, type ActionResult } from '@/lib/action-result';
import { endSession, startSession } from '@/lib/auth';
import { createRateLimiter } from '@/lib/rate-limit';
import { safeRedirect } from '@/lib/safe-redirect';

const limiter = createRateLimiter({ max: 10, windowMs: 15 * 60 * 1000 });

// Detrás de Caddy, X-Forwarded-For lo pone el proxy con la IP real del cliente.
async function clientIp(): Promise<string> {
  return (await headers()).get('x-forwarded-for')?.split(',')[0]?.trim() || 'local';
}

function sameSecret(a: string, b: string): boolean {
  const ha = createHash('sha256').update(a).digest();
  const hb = createHash('sha256').update(b).digest();
  return timingSafeEqual(ha, hb);
}

const field = (form: FormData, name: string) => String(form.get(name) ?? '');

export async function loginAction(_prev: ActionResult | null, form: FormData): Promise<ActionResult> {
  const email = field(form, 'email');
  if (!limiter.check(`login:${await clientIp()}:${email.trim().toLowerCase()}`)) {
    return { ok: false, error: 'Demasiados intentos. Esperá unos minutos.' };
  }
  const user = await verifyCredentials(await getDb(), email, field(form, 'password'));
  if (!user) return { ok: false, error: 'Email o contraseña incorrectos' };
  await startSession(user.id);
  redirect(safeRedirect(form.get('next')));
}

export async function registerAction(_prev: ActionResult | null, form: FormData): Promise<ActionResult> {
  const inviteCode = process.env.INVITE_CODE;
  if (!inviteCode) return { ok: false, error: 'El registro está deshabilitado' };
  if (!limiter.check(`registro:${await clientIp()}`)) {
    return { ok: false, error: 'Demasiados intentos. Esperá unos minutos.' };
  }
  if (!sameSecret(field(form, 'invite'), inviteCode)) return { ok: false, error: 'Código de invitación inválido' };

  const result = await runAction(async () =>
    createUser(await getDb(), { email: field(form, 'email'), password: field(form, 'password'), name: field(form, 'name') }),
  );
  if (!result.ok) return result;
  await startSession(result.data.id);
  redirect('/app/today');
}

export async function logoutAction(): Promise<void> {
  await endSession();
  redirect('/login');
}
```

```ts
export async function quickAddAction(text: string, context: QuickAddContext) {
  return act(async (db, user) => {
```

```tsx
const NEW_FOLDER = '__new';

export function ListDialog({ list, folders, onClose }: { list?: List; folders: Folder[]; onClose: () => void }) {
  const router = useRouter();
  const [name, setName] = useState(list?.name ?? '');
  const [color, setColor] = useState<string | null>(list?.color ?? LIST_COLORS[0]);
  const [folderId, setFolderId] = useState(list?.folderId ?? '');
  const [newFolder, setNewFolder] = useState('');
  const [error, setError] = useState<string | null>(null);
  const [pending, startTransition] = useTransition();

  function submit(e: React.FormEvent) {
    e.preventDefault();
    startTransition(async () => {
      let targetFolder: string | null = folderId || null;
      if (folderId === NEW_FOLDER) {
        const created = await createFolderAction(newFolder);
        if (!created.ok) return setError(created.error);
        targetFolder = created.data.id;
      }
      if (list) {
        const result = await updateListAction(list.id, { name, color, folderId: targetFolder });
        if (!result.ok) return setError(result.error);
        onClose();
      } else {
        const result = await createListAction({ name, color, folderId: targetFolder });
        if (!result.ok) return setError(result.error);
        onClose();
        router.push(`/app/list/${result.data.id}`);

      if (!result.ok) return setError(result.error);
```

```tsx
      value={title} onChange={(e) => setTitle(e.target.value)} aria-label="Título de la subtarea"

      onKeyDown={(e) => e.key === 'Enter' && e.currentTarget.blur()}
      className={`min-w-0 flex-1 bg-transparent text-sm outline-none ${subtask.done ? 'text-muted line-through' : ''}`}
    />

export function SubtaskList({ task, onError }: { task: TaskWithDetails; onError: (e: string | null) => void }) {

              onChange={(e) => run(() => updateSubtaskAction(s.id, { done: e.target.checked }))}
            />
            <SubtaskTitle subtask={s} onSave={(title) => run(() => updateSubtaskAction(s.id, { title }))} />
            <button
              onClick={() => run(() => deleteSubtaskAction(s.id))} aria-label={`Borrar ${s.title}`}
              className="rounded p-0.5 text-muted hover:bg-hover md:opacity-0 md:group-hover:opacity-100"
            >
              <X size={14} />
            </button>
          </li>
        ))}
      </ul>
      <form
        onSubmit={(e) => {
          e.preventDefault();
          if (!newTitle.trim()) return;
          const title = newTitle;
          setNewTitle('');
          run(() => addSubtaskAction(task.id, title));
        }}
      >
        <input
          value={newTitle} onChange={(e) => setNewTitle(e.target.value)} placeholder="+ Agregar subtarea"
```

```tsx
            <RotateCcw size={15} /> Restaurar

        </div>
      </div>
    );

  const control = 'rounded border border-line bg-transparent px-2 py-1 text-sm';

        {error && <p role="alert" className="text-sm text-danger">{error}</p>}
      </div>

  );
```
