# Notas — Plan 4: Servidor MCP con OAuth 2.1 y tokens personales

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Exponer las tareas de cada usuario a cualquier IA (Claude, ChatGPT, Cursor, Claude Code, n8n…) mediante un endpoint MCP en `/mcp` (Streamable HTTP, sin estado), autenticado con OAuth 2.1 (registro dinámico + PKCE + consentimiento) o con tokens personales `ntk_` creados desde Configuración.

**Architecture:** Cuatro tablas nuevas (`api_tokens`, `oauth_clients`, `oauth_codes`, `oauth_tokens`) con todos los secretos guardados como SHA-256. La lógica vive en el núcleo y es testeable sin Next: `src/core/api-tokens.ts` (tokens personales), `src/core/oauth.ts` (clientes, códigos, PKCE, emisión/rotación/revocación de tokens, conexiones) y `src/core/bearer.ts` (`authenticateBearer`). Los endpoints son route handlers delgados que reciben `Request` y devuelven `Response` (`/.well-known/*`, `/oauth/register`, `/oauth/token`, `/oauth/revoke`, `/mcp`); la pantalla de consentimiento es una página de servidor (`/oauth/authorize`) con dos server actions. Las herramientas MCP están en `src/mcp/tools.ts` (definiciones con zod + un despachador `callTool` que traduce errores de dominio a `isError: true`), separadas del transporte (`src/mcp/server.ts` arma un `McpServer` por request; `src/app/mcp/route.ts` autentica, limita y delega en `createMcpHandler` del SDK). Configuración suma la sección "Conexión con IA".

**Tech Stack:** Next.js 15.5 (App Router), React 19, Tailwind CSS 4, Drizzle ORM 0.45 + drizzle-kit 0.31, PostgreSQL / PGlite, Vitest, Playwright. Nuevas dependencias (versiones exactas): `@modelcontextprotocol/server@2.3.1`, `zod@4.6.5`; de desarrollo: `@modelcontextprotocol/client@2.3.1`.

**Spec:** `docs/superpowers/specs/2026-10-08-notas-design.md`, secciones "Servidor MCP" y el punto **MCP** de "Listas compartidas"; `docs/PROGRESO.md`.

## Investigación (2026-10-10)

- **Spec MCP vigente: `2026-07-28`** ([autorización](https://modelcontextprotocol.io/specification/2026-07-28/basic/authorization), [descubrimiento](https://modelcontextprotocol.io/specification/2026-07-28/basic/authorization/authorization-server-discovery), [registro de clientes](https://modelcontextprotocol.io/specification/2026-07-28/basic/authorization/client-registration), [versionado](https://modelcontextprotocol.io/specification/2026-07-28/basic/versioning)).
  - El servidor MCP **DEBE** publicar Protected Resource Metadata (RFC 9728) con `authorization_servers`; responder `401` con `WWW-Authenticate: Bearer resource_metadata="…"` (y **DEBERÍA** incluir `scope="…"`). Los clientes prueban primero `/.well-known/oauth-protected-resource/<ruta-del-mcp>` y después la raíz.
  - El AS publica RFC 8414 en `/.well-known/oauth-authorization-server` (issuer sin ruta). PKCE S256 obligatorio y anunciado en `code_challenge_methods_supported`.
  - `resource` (RFC 8707) va en la autorización y en el canje; el servidor **DEBE** validar que el token fue emitido para él (audiencia). Se acepta esquema/host en mayúsculas y sin barra final.
  - **Client ID Metadata Documents (CIMD) pasa a ser lo recomendado (SHOULD) y DCR (RFC 7591) queda "deprecated", pero se mantiene (MAY)** por compatibilidad. Los clientes eligen CIMD solo si el AS anuncia `client_id_metadata_document_supported: true`; si no, usan DCR.
  - Se recomienda emitir `iss` en las respuestas de autorización (RFC 9207) y anunciar `authorization_response_iss_parameter_supported: true`.
  - El protocolo `2026-07-28` es **sin estado** (sin `initialize`; versión y capacidades viajan en `_meta` de cada request). Los clientes "dual-era" caen a la versión `2025-11-25` (con `initialize`) si el servidor no es moderno.
- **SDK TypeScript** ([npm `@modelcontextprotocol/server`](https://www.npmjs.com/package/@modelcontextprotocol/server), README: "v2 … the stable release line, implementing the 2026-07-28 MCP spec"). Verificado bajando y ejecutando 2.3.1 (publicada 2026-10-05): `createMcpHandler(factory, options)` devuelve `{ fetch(request, { authInfo }) }` (Web `Request`/`Response`, ideal para un route handler de Next). Atiende **ambas eras**: tráfico moderno por request y tráfico 2025 con un fallback sin estado (`legacy: 'stateless'`, por defecto), en el que `GET`/`DELETE` devuelven `405` y las respuestas a `POST` llegan como SSE (`event: message` / `data: …`). `McpServer.registerTool(name, { title, description, inputSchema: z.object(...), annotations }, cb)`; la factory recibe `ctx.authInfo` (lo que pasamos en `fetch`). Requiere `zod ^4.2` (usa Standard Schema + JSON Schema de zod 4). El paquete v1 `@modelcontextprotocol/sdk@1.32.1` sigue publicándose pero solo habla hasta `2025-11-25`; se elige v2. El cliente `@modelcontextprotocol/client@2.3.1` (solo tests) acepta `fetch` propio y `versionNegotiation: { mode: 'auto' }` para forzar la era moderna.
- **Claude** ([Authentication for connectors](https://claude.com/docs/connectors/building/authentication), [soporte](https://support.claude.com/en/articles/11503834)): soporta DCR y CIMD "out of the box" (CIMD solo si el AS anuncia `client_id_metadata_document_supported: true` **y** `none` en `token_endpoint_auth_methods_supported`; si no, DCR). Callback de las apps alojadas: `https://claude.ai/api/mcp/auth_callback`; Claude Code usa loopback `http://localhost:<puerto>/callback` con puerto variable → comparar loopback **sin puerto**. Exige `401` (ignora `WWW-Authenticate` en un `200`), usa solo el primer `authorization_servers`, refresca reactivamente ante `401` y proactivamente 5 min antes de vencer, espera `invalid_grant` cuando el refresh ya no sirve, pide rotación de refresh para clientes públicos, `/token` en `application/x-www-form-urlencoded`, `/register` en JSON, timeouts de 10 s (30 s para refresh). Pide mostrar el host del redirect en el consentimiento y advertir si es loopback.
- **ChatGPT** ([Apps SDK – Authentication](https://developers.openai.com/apps-sdk/build/auth)): metadata con `issuer`, `authorization_endpoint`, `token_endpoint`, `code_challenge_methods_supported` (con `S256`) y `token_endpoint_auth_methods_supported`; DCR vía `registration_endpoint` (registra una vez por conexión); envía `resource` en autorización y canje. Si el AS cumple la identificación de issuer (`iss` en **todas** las respuestas, incluidas las de error, igual al `issuer`), usa el redirect fijo `https://chatgpt.com/connector_platform_oauth_redirect`; si no, uno por conexión `https://chatgpt.com/connector/oauth/{callback_id}`. No soporta `client_credentials`.

**Conclusión:** con **DCR + PKCE S256 + `resource` + `iss`** Notas funciona con Claude (web, Desktop, Code) y ChatGPT hoy. CIMD se deja para más adelante (exige que el servidor descargue URLs arbitrarias: riesgo SSRF y caché; ver Riesgos).

## Decisiones tomadas al planificar (resuelven ambigüedades)

- **SDK v2 (`@modelcontextprotocol/server`), no v1 (`@modelcontextprotocol/sdk`).** El spec dice "SDK oficial `@modelcontextprotocol/sdk`"; v2 es la línea estable del mismo SDK oficial, implementa la spec vigente y sigue atendiendo clientes 2025. Versiones exactas (sin `^`) para que una actualización del SDK no cambie el protocolo sin querer.
- **Sin estado:** `createMcpHandler` con un `McpServer` nuevo por request (factory) atado al `userId` autenticado. Sin sesiones ni SSE de servidor (GET/DELETE → 405 en la era 2025).
- **`authInfo.token`** se pasa como `'redacted'`: el SDK no necesita el token y así nunca puede terminar en un log.
- **Origin en `/mcp`:** la spec pide validar `Origin`. Si viene y no es el de `APP_URL` → `403`. Claude/ChatGPT llaman desde sus servidores (sin `Origin`). Consecuencia: el MCP Inspector en el navegador no funciona contra producción (aceptado). `/mcp` no tiene CORS.
- **CORS** (`Access-Control-Allow-Origin: *`, sin credenciales) solo en `/.well-known/*`, `/oauth/register`, `/oauth/token`, `/oauth/revoke`.
- **`resource_metadata`** del `401` apunta a `<APP_URL>/.well-known/oauth-protected-resource/mcp` (la URL que RFC 9728 deriva de `<APP_URL>/mcp`); el mismo documento se sirve también en la raíz `/.well-known/oauth-protected-resource` para clientes que solo prueban la raíz.
- **Issuer = `APP_URL`** (sin barra final). `APP_URL` es obligatoria en producción y se lee en cada request (`appUrl()`), nunca en el build: todos los route handlers llevan `export const dynamic = 'force-dynamic'`.
- **Scope único `tasks`.** Se anuncia en `scopes_supported` y en el `WWW-Authenticate`. Si el cliente pide otros scopes se ignoran y se concede `tasks` (la respuesta de token informa `scope: "tasks"`, RFC 6749 §5.1). No se anuncia `offline_access`, pero siempre se emite refresh token.
- **Solo clientes públicos:** `token_endpoint_auth_methods_supported: ["none"]`. Si un cliente pide en DCR otro método, se registra igual como `none` y se lo informa en la respuesta (RFC 7591 §3.2.1 permite que el servidor reemplace valores). `grant_types`/`response_types` pedidos se ignoran: se responde siempre `["authorization_code","refresh_token"]` / `["code"]`.
- **Redirect URIs:** `https` (cualquier host) o `http` solo para `localhost`, `127.0.0.1`, `[::1]`; sin fragmento ni usuario/contraseña; máx. 10 por cliente. Comparación exacta, salvo loopback `http`, donde se ignora el puerto (RFC 8252 §7.3; lo pide Claude Code).
- **Errores de autorización:** si `client_id` o `redirect_uri` no son válidos se muestra un error en pantalla y **nunca** se redirige. El resto (`response_type`, PKCE, `resource`) se devuelve al `redirect_uri` con `error`, `error_description`, `state` e `iss`.
- **Consentimiento en cada autorización** (con DCR cada conexión es un cliente nuevo). Muestra el nombre del cliente (texto escapado por React), el **host** del redirect, la cuenta y una advertencia si el redirect es loopback. Se valida primero la solicitud y después el login, así un pedido inválido no obliga a loguearse.
- **Login/registro con `next`:** `/oauth/authorize` sin sesión redirige a `/login?next=<encodeURIComponent(ruta+query)>`. Se corrige el hueco conocido: el link "Registrate" lleva `next`, la página de registro lo pasa al formulario y `registerAction` redirige a `safeRedirect(next)`.
- **Códigos:** 5 min, un solo uso (marcado atómico `UPDATE … WHERE used_at IS NULL`). Reusar un código ya canjeado revoca los tokens emitidos con él (OAuth 2.1 §4.1.3): el código guarda el `family_id` de esos tokens. Un código fallado (cliente, redirect o PKCE incorrectos) queda quemado.
- **Tokens:** access `nat_` 1 h; refresh `nrt_` 60 días. **Rotación** en cada refresh: la fila vieja se revoca (access y refresh) y se crea otra con el mismo `family_id`. **Reuso** de un refresh ya rotado o revocado → se revoca toda la familia y `invalid_grant`. Dos refresh simultáneos con el mismo token desconectan al cliente (riesgo aceptado, ver Riesgos).
- **Audiencia:** cada código/token guarda `resource` (siempre `<APP_URL>/mcp`); `authenticateAccessToken` lo compara con el recurso actual.
- **Revocación (RFC 7009)** en `/oauth/revoke`: siempre `200`; revoca la fila del token (y con ella su par). Si viene `client_id`, solo revoca tokens de ese cliente.
- **Tokens personales:** `ntk_` + 32 bytes base64url, se muestran una sola vez; en la base, hash + `prefix` (primeros 12 caracteres) para reconocerlos. Máx. 20 activos por usuario. Revocar = `revoked_at` (no se borran).
- **`last_used_at`** se actualiza como mucho una vez por minuto por token (evita una escritura por request).
- **Limpieza:** `purgeExpiredOAuthData(db, now)` borra códigos vencidos hace más de 1 día, tokens con refresh vencido o revocados hace más de 30 días, y clientes de más de 1 día sin códigos ni tokens (DCR sin autenticar genera clientes huérfanos). Igual que `purgeTrash`/`purgeExpiredSessions`: **lo programa el Plan 5** (cron); acá solo se implementa y testea.
- **Límites de frecuencia** (en memoria, una instancia): `/oauth/register` 20/h por IP; `/oauth/token` 60/min por IP; `/oauth/revoke` 60/min por IP; `/mcp` 120/min por usuario; crear token personal 10/h por usuario; `share_list` por MCP 20/h por usuario (igual que la web, frena el sondeo de emails).
- **Herramientas MCP:** salida JSON compacta en un bloque `text`. Tareas: `id, title, description, list_id, list_name, due_date, due_time, priority, status, completed_at, deleted_at, tags, other_tags, assignee` (email o `null`) y `subtasks [{id,title,done}]`; nunca `user_id`, `external_id` ni `assignee_id`. Esquemas zod `strict()` (una clave mal escrita da error claro en vez de ignorarse). `ValidationError`/`NotFoundError` → `isError: true` con el mensaje; cualquier otro error → mensaje genérico + `console.error`.
- **`assignee_email`** se resuelve con `getListMembers` de la lista de la tarea (dueño o miembros); si el email no está entre ellos → `ValidationError`, sin revelar si la cuenta existe. `unshare_list` recibe el **email** del miembro.
- **`list_tasks`:** `limit` 1–200 (por defecto 50), `offset`; devuelve `{ tasks, count, has_more }` (pide `limit + 1` al núcleo).
- **Tests de route handlers:** `setDbForTests(db)` en `src/db/index.ts` (lanza si `NODE_ENV !== 'test'`; Vitest pone `test`). Los route handlers no importan `@/lib/auth` (`server-only` + `cookies()`); solo la página/acciones de `/oauth/authorize` lo usan y se prueban por e2e.
- **Clickjacking:** `next.config.ts` agrega `X-Frame-Options: DENY` y `Content-Security-Policy: frame-ancestors 'none'` a todas las rutas (la app nunca se embebe; protege el botón "Permitir").

**Firmas nuevas del núcleo** (las usan tasks posteriores; verificar contra el código al implementar):
- `secrets.ts`: `generateSecret(prefix, bytes = 32)`, `sha256Hex(v)`, `sha256Base64Url(v)`, `safeEqual(a, b)`.

```ts
/**
 * URL pública de la app (p. ej. https://notas.example.com): es el issuer de OAuth y la base del recurso MCP.
 * Se lee en cada llamada (nunca en el build) para que la imagen de producción tome la variable del entorno.
 */
export function appUrl(): string {
  const raw = process.env.APP_URL?.trim();
  if (!raw) {
    if (process.env.NODE_ENV === 'production') {
      throw new Error('APP_URL no está configurada (p. ej. https://notas.example.com)');
    }
    return 'http://localhost:3000';
  }
  let url: URL;
  try {
```

```ts
import { createHash, randomBytes, timingSafeEqual } from 'node:crypto';

/** Secreto aleatorio en base64url con un prefijo legible que indica su tipo (p. ej. "ntk_…"). */
export function generateSecret(prefix: string, bytes = 32): string {
  return `${prefix}${randomBytes(bytes).toString('base64url')}`;
}

/** Hash con el que se guardan los secretos en la base: nunca se guardan en claro. */
export function sha256Hex(value: string): string {
  return createHash('sha256').update(value).digest('hex');
}

/** SHA-256 en base64url sin relleno (PKCE S256, RFC 7636). */
export function sha256Base64Url(value: string): string {
  return createHash('sha256').update(value).digest('base64url');
}

/** Comparación en tiempo constante; se comparan hashes para no filtrar el largo. */
export function safeEqual(a: string, b: string): boolean {
  return timingSafeEqual(createHash('sha256').update(a).digest(), createHash('sha256').update(b).digest());
```

```ts
import { and, desc, eq, isNull, lt, or, sql } from 'drizzle-orm';
import { apiTokens } from '@/db/schema';
import type { DB } from '@/db/types';
import { NotFoundError, ValidationError, isUuid } from './errors';
import { generateSecret, sha256Hex } from './secrets';

export const PERSONAL_TOKEN_PREFIX = 'ntk_';
const MAX_ACTIVE_TOKENS = 20;
/** "ntk_" + 8 caracteres: alcanza para reconocer el token en la UI sin servir para usarlo. */
const DISPLAY_PREFIX_LENGTH = 12;
/** last_used_at se escribe como mucho una vez por minuto por token. */
const TOUCH_INTERVAL_MS = 60_000;

/** Lo que se muestra de un token (nunca el token ni su hash). */
export interface ApiTokenSummary {
  id: string;
  name: string;
  prefix: string;
  createdAt: Date;
  lastUsedAt: Date | null;
}

const summaryColumns = {
  id: apiTokens.id,
  name: apiTokens.name,
  prefix: apiTokens.prefix,
  createdAt: apiTokens.createdAt,
  lastUsedAt: apiTokens.lastUsedAt,
};

function cleanTokenName(name: unknown): string {
  if (typeof name !== 'string') throw new ValidationError('El nombre debe ser texto');
  const clean = name.trim();
  if (!clean) throw new ValidationError('Poné un nombre para reconocer el token (p. ej. "Cursor")');
  if (clean.length > 100) throw new ValidationError('El nombre no puede superar los 100 caracteres');
  return clean;
}

/** Crea un token personal. El token en claro solo se devuelve acá; en la base queda su hash. */
export async function createApiToken(
  db: DB, userId: string, name: string,
): Promise<{ token: string; summary: ApiTokenSummary }> {
  const clean = cleanTokenName(name);
  const [{ count }] = await db
    .select({ count: sql<number>`count(*)` })
    .from(apiTokens)
    .where(and(eq(apiTokens.userId, userId), isNull(apiTokens.revokedAt)));
  if (Number(count) >= MAX_ACTIVE_TOKENS) {
    throw new ValidationError(`Podés tener como máximo ${MAX_ACTIVE_TOKENS} tokens activos: revocá alguno`);
  }
  const token = generateSecret(PERSONAL_TOKEN_PREFIX);
  const [summary] = await db
    .insert(apiTokens)
    .values({ userId, name: clean, tokenHash: sha256Hex(token), prefix: token.slice(0, DISPLAY_PREFIX_LENGTH) })
    .returning(summaryColumns);
  return { token, summary };
}

/** Tokens activos del usuario, los más nuevos primero. */
export async function listApiTokens(db: DB, userId: string): Promise<ApiTokenSummary[]> {
  return db
    .select(summaryColumns)
    .from(apiTokens)
    .where(and(eq(apiTokens.userId, userId), isNull(apiTokens.revokedAt)))
    .orderBy(desc(apiTokens.createdAt), desc(apiTokens.id));
}

/** Revoca un token activo del usuario; NotFoundError si no existe, es de otro o ya estaba revocado. */
export async function revokeApiToken(db: DB, userId: string, tokenId: string): Promise<void> {
  if (!isUuid(tokenId)) throw new NotFoundError('El token');
  const revoked = await db
    .update(apiTokens)
    .set({ revokedAt: new Date() })
    .where(and(eq(apiTokens.id, tokenId), eq(apiTokens.userId, userId), isNull(apiTokens.revokedAt)))
    .returning({ id: apiTokens.id });
  if (revoked.length === 0) throw new NotFoundError('El token');
}

/** Usuario dueño de un token personal activo, o null. */
export async function authenticateApiToken(
  db: DB, token: string, now: Date = new Date(),
): Promise<{ userId: string; tokenId: string } | null> {
  if (!token.startsWith(PERSONAL_TOKEN_PREFIX)) return null;
  const [row] = await db
    .select({ id: apiTokens.id, userId: apiTokens.userId })
    .from(apiTokens)
    .where(and(eq(apiTokens.tokenHash, sha256Hex(token)), isNull(apiTokens.revokedAt)));
  if (!row) return null;
  await db
    .update(apiTokens)
    .set({ lastUsedAt: now })
    .where(and(
      eq(apiTokens.id, row.id),
      or(isNull(apiTokens.lastUsedAt), lt(apiTokens.lastUsedAt, new Date(now.getTime() - TOUCH_INTERVAL_MS))),
    ));
  return { userId: row.userId, tokenId: row.id };
}
```

```ts
import { eq } from 'drizzle-orm';
import { oauthClients } from '@/db/schema';
import type { DB } from '@/db/types';
import { generateSecret } from './secrets';

/** Único scope: acceso completo a las listas y tareas del usuario. */
export const OAUTH_SCOPE = 'tasks';

const CLIENT_ID_PREFIX = 'ncl_';
const DEFAULT_CLIENT_NAME = 'Aplicación sin nombre';
const MAX_REDIRECT_URIS = 10;
const MAX_URI_LENGTH = 2000;
const LOOPBACK_HOSTS = new Set(['localhost', '127.0.0.1', '[::1]']);

export type OAuthErrorCode =
  | 'invalid_request'
  | 'invalid_client'
  | 'invalid_grant'
  | 'unsupported_grant_type'
  | 'unsupported_response_type'
  | 'invalid_scope'
  | 'invalid_target'
  | 'access_denied'
  | 'invalid_redirect_uri'
  | 'invalid_client_metadata';

/** Error de protocolo OAuth: `code` va en `error` y el mensaje en `error_description`. */
export class OAuthError extends Error {
  readonly code: OAuthErrorCode;

  constructor(code: OAuthErrorCode, message: string) {
    super(message);
    this.name = 'OAuthError';
    this.code = code;
  }
}

export type OAuthClient = typeof oauthClients.$inferSelect;

// ---------- Redirect URIs y recurso ----------

function parseRedirectUri(value: unknown): URL | null {
  if (typeof value !== 'string' || value.length > MAX_URI_LENGTH || value.includes('#')) return null;
  let url: URL;
  try {
    url = new URL(value);
  } catch {
    return null;
  }
  if (url.username || url.password) return null;
  if (url.protocol === 'https:') return url;
  if (url.protocol === 'http:' && LOOPBACK_HOSTS.has(url.hostname)) return url;
  return null;
}

/** https (cualquier host) o http solo hacia la propia máquina (localhost, 127.0.0.1, [::1]); sin fragmento. */
export function isAllowedRedirectUri(value: unknown): boolean {
  return parseRedirectUri(value) !== null;
}

/** ¿Vuelve a un programa de la propia computadora? (el consentimiento muestra una advertencia) */
export function isLoopbackRedirect(value: string): boolean {
  return parseRedirectUri(value)?.protocol === 'http:';
}

/**
 * ¿`requested` es una de las URIs registradas? Comparación exacta, salvo loopback http, donde el puerto se
 * ignora porque las apps nativas (p. ej. Claude Code) usan un puerto distinto en cada sesión (RFC 8252 §7.3).
 */
export function matchesRegisteredRedirect(registered: readonly string[], requested: string): boolean {
  const req = parseRedirectUri(requested);
  if (!req) return false;
  if (registered.includes(requested)) return true;
  if (req.protocol !== 'http:') return false;
  return registered.some((value) => {
    const reg = parseRedirectUri(value);
    return reg !== null && reg.protocol === 'http:' && reg.hostname === req.hostname
      && reg.pathname === req.pathname && reg.search === req.search;
  });
}

function canonicalResource(value: string): string | null {
  if (value.includes('#')) return null;
  let url: URL;
  try {
    url = new URL(value);
  } catch {
    return null;
  }
  return `${url.protocol}//${url.host}${url.pathname.replace(/\/+$/, '')}${url.search}`;
}

/** Compara identificadores de recurso (RFC 8707) tolerando mayúsculas en esquema/host, puerto por defecto y barra final. */
export function sameResource(candidate: string, expected: string): boolean {
  const a = canonicalResource(candidate);
  return a !== null && a === canonicalResource(expected);
}

// ---------- Clientes (registro dinámico, RFC 7591) ----------

function cleanClientName(value: unknown): string {
  if (value === undefined || value === null) return DEFAULT_CLIENT_NAME;
  if (typeof value !== 'string') throw new OAuthError('invalid_client_metadata', 'client_name debe ser texto');
  const clean = value.replace(/[\x00-\x1f\x7f]/g, '').trim().slice(0, 100);
  return clean || DEFAULT_CLIENT_NAME;
}

/**
 * Registra un cliente público. Solo importan `redirect_uris` y `client_name`: el resto de la metadata
 * (método de autenticación, grant types…) se ignora y la respuesta informa los valores reales.
 */
export async function registerClient(db: DB, metadata: unknown, now: Date = new Date()): Promise<OAuthClient> {
  if (typeof metadata !== 'object' || metadata === null || Array.isArray(metadata)) {
    throw new OAuthError('invalid_client_metadata', 'El cuerpo debe ser un objeto JSON');
  }
  const { redirect_uris: uris, client_name: name } = metadata as Record<string, unknown>;
  if (!Array.isArray(uris) || uris.length === 0) {
    throw new OAuthError('invalid_redirect_uri', 'redirect_uris es obligatorio y no puede estar vacío');
  }
  if (uris.length > MAX_REDIRECT_URIS) {
    throw new OAuthError('invalid_redirect_uri', `Se admiten como máximo ${MAX_REDIRECT_URIS} redirect_uris`);
  }
  for (const uri of uris) {
    if (!isAllowedRedirectUri(uri)) {
      throw new OAuthError(
        'invalid_redirect_uri',
        `redirect_uri no permitida: ${String(uri).slice(0, 200)} (usá https, o http solo para localhost/127.0.0.1)`,
      );
    }
  }
  const [client] = await db
    .insert(oauthClients)
    .values({
      clientId: generateSecret(CLIENT_ID_PREFIX, 16),
      clientName: cleanClientName(name),
      redirectUris: [...new Set(uris as string[])],
      createdAt: now,
    })
    .returning();
  return client;
}

export async function getClient(db: DB, clientId: string): Promise<OAuthClient | null> {
  if (!clientId.startsWith(CLIENT_ID_PREFIX) || clientId.length > 100) return null;
  const [client] = await db.select().from(oauthClients).where(eq(oauthClients.clientId, clientId));
  return client ?? null;
}
```

```ts
// ---------- Solicitud de autorización y códigos ----------

export const CODE_TTL_MS = 5 * 60 * 1000;
const CODE_PREFIX = 'nac_';
/** S256 = base64url(sha256(verifier)) sin relleno: siempre 43 caracteres. */
const CHALLENGE_RE = /^[A-Za-z0-9_-]{43}$/;

export interface AuthorizationParams {
  responseType?: string;
  clientId?: string;
  redirectUri?: string;
  codeChallenge?: string;
  codeChallengeMethod?: string;
  state?: string;
  scope?: string;
  resource?: string;
}

/** Nombre del parámetro OAuth de cada campo (query de /oauth/authorize y campos del formulario de consentimiento). */
export const AUTHORIZATION_PARAM_NAMES: Record<keyof AuthorizationParams, string> = {
  responseType: 'response_type',
  clientId: 'client_id',
  redirectUri: 'redirect_uri',
  codeChallenge: 'code_challenge',
  codeChallengeMethod: 'code_challenge_method',
  state: 'state',
  scope: 'scope',
  resource: 'resource',
};

/** Arma los parámetros desde cualquier fuente (`get` devuelve undefined si falta o está repetido); vacío = ausente. */
export function authorizationParamsFrom(get: (name: string) => string | undefined): AuthorizationParams {
  const params: AuthorizationParams = {};
  for (const field of Object.keys(AUTHORIZATION_PARAM_NAMES) as (keyof AuthorizationParams)[]) {
    const value = get(AUTHORIZATION_PARAM_NAMES[field]);
    if (value !== undefined && value !== '') params[field] = value;
  }
  return params;
}

export type AuthorizationCheck =
  | {
    ok: true; client: OAuthClient; redirectUri: string; codeChallenge: string; state?: string; scope: string;
    resource: string;
  }
  /** client_id o redirect_uri inválidos: se muestra el error, NUNCA se redirige (RFC 6749 §4.1.2.1). */
  | { ok: false; redirect: false; error: string }
  /** Error que se devuelve al redirect_uri (ya validado). */
  | { ok: false; redirect: true; redirectUri: string; state?: string; error: OAuthErrorCode; description: string };

/**
 * Valida una solicitud de autorización (code + PKCE S256). Si viene `resource` debe ser el recurso MCP propio;
 * el scope pedido se ignora y se concede siempre `tasks`.
 */
export async function validateAuthorizationRequest(
  db: DB, params: AuthorizationParams, opts: { resource: string },
): Promise<AuthorizationCheck> {
  const client = params.clientId ? await getClient(db, params.clientId) : null;
  if (!client) {
    return { ok: false, redirect: false, error: 'La aplicación que pide acceso no está registrada en Notas (client_id desconocido).' };
  }
  const redirectUri = params.redirectUri;
  if (!redirectUri || !matchesRegisteredRedirect(client.redirectUris, redirectUri)) {
    return {
      ok: false, redirect: false,
      error: 'La dirección de retorno (redirect_uri) no coincide con ninguna de las registradas por la aplicación.',
    };
  }
  const fail = (error: OAuthErrorCode, description: string): AuthorizationCheck => ({
    ok: false, redirect: true, redirectUri, state: params.state, error, description,
  });
  if (params.responseType !== 'code') return fail('unsupported_response_type', 'Solo se admite response_type=code');
  if (params.codeChallengeMethod !== 'S256') return fail('invalid_request', 'PKCE es obligatorio: code_challenge_method=S256');
  if (!params.codeChallenge || !CHALLENGE_RE.test(params.codeChallenge)) {
    return fail('invalid_request', 'code_challenge inválido (base64url de 43 caracteres)');
  }
  if (params.resource !== undefined && !sameResource(params.resource, opts.resource)) {
    return fail('invalid_target', `resource debe ser ${opts.resource}`);
  }
  return {
    ok: true, client, redirectUri, codeChallenge: params.codeChallenge, state: params.state, scope: OAUTH_SCOPE,
    resource: opts.resource,
  };
}

/** Agrega parámetros a la URI de retorno conservando su query (RFC 6749 §3.1.2); ignora los undefined. */
export function buildRedirectUrl(redirectUri: string, params: Record<string, string | undefined>): string {
  const url = new URL(redirectUri);
  for (const [key, value] of Object.entries(params)) {
    if (value !== undefined) url.searchParams.set(key, value);
  }
  return url.toString();
}

export interface NewAuthorizationCode {
  clientId: string;
  userId: string;
  redirectUri: string;
  codeChallenge: string;
  scope: string;
  resource: string;
}

/** Emite un código de un solo uso (5 min). Se devuelve en claro solo acá; en la base queda su hash. */
export async function createAuthorizationCode(
  db: DB, input: NewAuthorizationCode, now: Date = new Date(),
): Promise<string> {
  const code = generateSecret(CODE_PREFIX);
  await db.insert(oauthCodes).values({
    ...input, codeHash: sha256Hex(code), expiresAt: new Date(now.getTime() + CODE_TTL_MS), createdAt: now,
  });
  return code;
}
```

```ts
// ---------- Tokens ----------

export const ACCESS_TOKEN_PREFIX = 'nat_';
export const REFRESH_TOKEN_PREFIX = 'nrt_';
export const ACCESS_TOKEN_TTL_MS = 60 * 60 * 1000;
export const REFRESH_TOKEN_TTL_MS = 60 * 24 * 60 * 60 * 1000;
const TOUCH_INTERVAL_MS = 60_000;
const DAY_MS = 24 * 60 * 60 * 1000;
/** RFC 7636 §4.1: 43 a 128 caracteres "unreserved". */
const VERIFIER_RE = /^[A-Za-z0-9._~-]{43,128}$/;

/** PKCE S256: base64url(sha256(verifier)) === challenge, en tiempo constante. */
export function verifyPkce(verifier: unknown, challenge: string): boolean {
  if (typeof verifier !== 'string' || !VERIFIER_RE.test(verifier)) return false;
  return safeEqual(sha256Base64Url(verifier), challenge);
}

/** Respuesta del endpoint de token (RFC 6749 §5.1). */
export interface TokenResponse {
  access_token: string;
  token_type: 'Bearer';
  expires_in: number;
  refresh_token: string;
  scope: string;
}

interface TokenGrant {
  clientId: string;
  userId: string;
  scope: string;
  resource: string;
  familyId: string;
}

async function issueTokens(db: DB, grant: TokenGrant, now: Date): Promise<TokenResponse> {
  const accessToken = generateSecret(ACCESS_TOKEN_PREFIX);
  const refreshToken = generateSecret(REFRESH_TOKEN_PREFIX);
  await db.insert(oauthTokens).values({
    ...grant,
    accessTokenHash: sha256Hex(accessToken),
    refreshTokenHash: sha256Hex(refreshToken),
    accessExpiresAt: new Date(now.getTime() + ACCESS_TOKEN_TTL_MS),
    refreshExpiresAt: new Date(now.getTime() + REFRESH_TOKEN_TTL_MS),
    createdAt: now,
  });
  return {
    access_token: accessToken, token_type: 'Bearer', expires_in: ACCESS_TOKEN_TTL_MS / 1000,
    refresh_token: refreshToken, scope: grant.scope,
  };
}

async function revokeFamily(db: DB, familyId: string, now: Date): Promise<void> {
  await db
    .update(oauthTokens)
    .set({ revokedAt: now })
    .where(and(eq(oauthTokens.familyId, familyId), isNull(oauthTokens.revokedAt)));
}

function checkResourceParam(resource: string | undefined, expected: string): void {
  if (resource !== undefined && !sameResource(resource, expected)) {
    throw new OAuthError('invalid_target', `resource debe ser ${expected}`);
  }
}

/**
 * Las transacciones devuelven el error en vez de lanzarlo: así se confirma lo que tiene que quedar
 * (el código quemado, la familia revocada) y el error se lanza afuera.
 */
type Outcome = { tokens: TokenResponse } | { error: OAuthError };

function unwrap(outcome: Outcome): TokenResponse {
  if ('error' in outcome) throw outcome.error;
  return outcome.tokens;
}

export interface CodeExchangeInput {
  code?: string;
  clientId?: string;
  redirectUri?: string;
  codeVerifier?: string;
  resource?: string;
}

/** grant_type=authorization_code: código de un solo uso + PKCE + mismo cliente y redirect_uri. */
export async function exchangeAuthorizationCode(
  db: DB, input: CodeExchangeInput, opts: { resource: string; now?: Date },
): Promise<TokenResponse> {
  const now = opts.now ?? new Date();
  const { code, clientId, redirectUri, codeVerifier } = input;
  if (!code || !clientId || !redirectUri || !codeVerifier) {
    throw new OAuthError('invalid_request', 'Faltan code, client_id, redirect_uri o code_verifier');
  }
  checkResourceParam(input.resource, opts.resource);
  const codeHash = sha256Hex(code);
  return unwrap(await db.transaction(async (tx): Promise<Outcome> => {
    // Marcado atómico: de dos canjes simultáneos, solo uno obtiene la fila.
    const [row] = await tx
      .update(oauthCodes)
      .set({ usedAt: now })
      .where(and(eq(oauthCodes.codeHash, codeHash), isNull(oauthCodes.usedAt)))
      .returning();
    if (!row) {
      // Reuso de un código ya canjeado: se revocan los tokens emitidos con él (OAuth 2.1 §4.1.3).
      const [used] = await tx.select({ familyId: oauthCodes.familyId }).from(oauthCodes).where(eq(oauthCodes.codeHash, codeHash));
      if (used?.familyId) await revokeFamily(tx, used.familyId, now);
      return { error: new OAuthError('invalid_grant', 'El código no es válido o ya se usó') };
    }
    if (row.expiresAt <= now) return { error: new OAuthError('invalid_grant', 'El código venció') };
    if (row.clientId !== clientId || row.redirectUri !== redirectUri) {
      return { error: new OAuthError('invalid_grant', 'El código no corresponde a este cliente o redirect_uri') };
    }
    if (!verifyPkce(codeVerifier, row.codeChallenge)) {
      return { error: new OAuthError('invalid_grant', 'code_verifier no coincide con el code_challenge') };
    }
    const familyId = randomUUID();
    await tx.update(oauthCodes).set({ familyId }).where(eq(oauthCodes.codeHash, codeHash));
    return {
      tokens: await issueTokens(tx, {
        clientId: row.clientId, userId: row.userId, scope: row.scope, resource: row.resource, familyId,
      }, now),
    };
  }));
}

export interface RefreshInput {
  refreshToken?: string;
  clientId?: string;
  resource?: string;
}

/**
 * grant_type=refresh_token con rotación: la fila vieja se revoca y se emite otra de la misma familia.
 * Reusar un refresh ya rotado/revocado, o presentarlo desde otro cliente, revoca toda la familia.
 */
export async function refreshAccessToken(
  db: DB, input: RefreshInput, opts: { resource: string; now?: Date },
): Promise<TokenResponse> {
  const now = opts.now ?? new Date();
  const { refreshToken, clientId } = input;
  if (!refreshToken || !clientId) throw new OAuthError('invalid_request', 'Faltan refresh_token o client_id');
  checkResourceParam(input.resource, opts.resource);
  const hash = sha256Hex(refreshToken);
  return unwrap(await db.transaction(async (tx): Promise<Outcome> => {
    const [row] = await tx
      .update(oauthTokens)
      .set({ revokedAt: now })
      .where(and(eq(oauthTokens.refreshTokenHash, hash), isNull(oauthTokens.revokedAt)))
      .returning();
    if (!row) {
      const [old] = await tx.select({ familyId: oauthTokens.familyId }).from(oauthTokens).where(eq(oauthTokens.refreshTokenHash, hash));
      if (old) await revokeFamily(tx, old.familyId, now);
      return { error: new OAuthError('invalid_grant', 'El refresh token no es válido') };
    }
    if (row.clientId !== clientId) {
      await revokeFamily(tx, row.familyId, now);
      return { error: new OAuthError('invalid_grant', 'El refresh token no corresponde a este cliente') };
    }
    if (row.refreshExpiresAt <= now) return { error: new OAuthError('invalid_grant', 'El refresh token venció') };
    return {
      tokens: await issueTokens(tx, {
        clientId: row.clientId, userId: row.userId, scope: row.scope, resource: row.resource, familyId: row.familyId,
      }, now),
    };
  }));
}

/** Revocación (RFC 7009): revoca la fila del token (access y refresh juntos). Desconocido = sin efecto. */
export async function revokeToken(
  db: DB, input: { token?: string; clientId?: string }, now: Date = new Date(),
): Promise<void> {
  if (!input.token) throw new OAuthError('invalid_request', 'Falta token');
  const column = input.token.startsWith(REFRESH_TOKEN_PREFIX) ? oauthTokens.refreshTokenHash : oauthTokens.accessTokenHash;
  const conditions: SQL[] = [eq(column, sha256Hex(input.token)), isNull(oauthTokens.revokedAt)];
  if (input.clientId) conditions.push(eq(oauthTokens.clientId, input.clientId));
  await db.update(oauthTokens).set({ revokedAt: now }).where(and(...conditions));
}

/** Usuario y cliente de un access token vigente emitido para `resource`, o null. */
export async function authenticateAccessToken(
  db: DB, token: string, opts: { resource: string; now?: Date },
): Promise<{ userId: string; clientId: string } | null> {
  if (!token.startsWith(ACCESS_TOKEN_PREFIX)) return null;
  const now = opts.now ?? new Date();
  const [row] = await db
    .select({ id: oauthTokens.id, userId: oauthTokens.userId, clientId: oauthTokens.clientId, resource: oauthTokens.resource })
    .from(oauthTokens)
    .where(and(
      eq(oauthTokens.accessTokenHash, sha256Hex(token)),
      isNull(oauthTokens.revokedAt),
      gt(oauthTokens.accessExpiresAt, now),
    ));
  if (!row || !sameResource(row.resource, opts.resource)) return null;
  await db
    .update(oauthTokens)
    .set({ lastUsedAt: now })
    .where(and(
      eq(oauthTokens.id, row.id),
      or(isNull(oauthTokens.lastUsedAt), lt(oauthTokens.lastUsedAt, new Date(now.getTime() - TOUCH_INTERVAL_MS))),
    ));
  return { userId: row.userId, clientId: row.clientId };
}

// ---------- Conexiones del usuario ----------

/** App conectada por OAuth (tiene al menos un par de tokens vigente). */
export interface OAuthConnection {
  clientId: string;
  clientName: string;
  lastUsedAt: Date | null;
}

export async function listOAuthConnections(db: DB, userId: string, now: Date = new Date()): Promise<OAuthConnection[]> {
  return db
    .select({ clientId: oauthClients.clientId, clientName: oauthClients.clientName, lastUsedAt: max(oauthTokens.lastUsedAt) })
    .from(oauthTokens)
    .innerJoin(oauthClients, eq(oauthClients.clientId, oauthTokens.clientId))
    .where(and(eq(oauthTokens.userId, userId), isNull(oauthTokens.revokedAt), gt(oauthTokens.refreshExpiresAt, now)))
    .groupBy(oauthClients.clientId, oauthClients.clientName)
    .orderBy(asc(oauthClients.clientName), asc(oauthClients.clientId));
}

/** Desconecta una app: revoca todos sus tokens del usuario. NotFoundError si no había ninguno vigente. */
export async function revokeOAuthConnection(
  db: DB, userId: string, clientId: string, now: Date = new Date(),
): Promise<void> {
  const revoked = await db
    .update(oauthTokens)
    .set({ revokedAt: now })
    .where(and(eq(oauthTokens.userId, userId), eq(oauthTokens.clientId, String(clientId)), isNull(oauthTokens.revokedAt)))
    .returning({ id: oauthTokens.id });
  if (revoked.length === 0) throw new NotFoundError('La conexión');
}

/**
 * Borra códigos vencidos hace más de un día, tokens con el refresh vencido o revocados hace más de 30 días,
 * y clientes de más de un día sin códigos ni tokens. Opera sobre TODOS los usuarios: solo para el cron (Plan 5).
 */
export async function purgeExpiredOAuthData(
  db: DB, now: Date = new Date(),
): Promise<{ codes: number; tokens: number; clients: number }> {
  const dayAgo = new Date(now.getTime() - DAY_MS);
  const codes = await db
    .delete(oauthCodes)
    .where(lt(oauthCodes.expiresAt, dayAgo))
    .returning({ codeHash: oauthCodes.codeHash });
  const tokens = await db
    .delete(oauthTokens)
    .where(or(lt(oauthTokens.refreshExpiresAt, now), lt(oauthTokens.revokedAt, new Date(now.getTime() - 30 * DAY_MS))))
    .returning({ id: oauthTokens.id });
  const orphans = await db
    .select({ clientId: oauthClients.clientId })
    .from(oauthClients)
    .where(and(
      lt(oauthClients.createdAt, dayAgo),
      notExists(db.select({ one: sql`1` }).from(oauthTokens).where(eq(oauthTokens.clientId, oauthClients.clientId))),
      notExists(db.select({ one: sql`1` }).from(oauthCodes).where(eq(oauthCodes.clientId, oauthClients.clientId))),
    ));
  if (orphans.length > 0) {
```

```ts
import type { DB } from '@/db/types';
import { PERSONAL_TOKEN_PREFIX, authenticateApiToken } from './api-tokens';
import { ACCESS_TOKEN_PREFIX, authenticateAccessToken } from './oauth';

/** Quién llama al MCP y con qué credencial. */
export type BearerAuth =
  | { userId: string; via: 'personal'; tokenId: string }
  | { userId: string; via: 'oauth'; clientId: string };

/** Los tokens reales miden menos de 50 caracteres: lo demás se descarta sin consultar la base. */
const MAX_TOKEN_LENGTH = 200;

/** Resuelve el token de un header `Authorization: Bearer …` (personal `ntk_` u OAuth `nat_`). */
export async function authenticateBearer(
  db: DB, token: string, opts: { resource: string; now?: Date },
): Promise<BearerAuth | null> {
  if (!token || token.length > MAX_TOKEN_LENGTH) return null;
  if (token.startsWith(PERSONAL_TOKEN_PREFIX)) {
    const found = await authenticateApiToken(db, token, opts.now);
    return found && { userId: found.userId, via: 'personal', tokenId: found.tokenId };
  }
  if (token.startsWith(ACCESS_TOKEN_PREFIX)) {
    const found = await authenticateAccessToken(db, token, opts);
    return found && { userId: found.userId, via: 'oauth', clientId: found.clientId };
  }
  return null;
}
```

```ts
import type { OAuthError } from '@/core/oauth';
import { clientIpFrom, trustedProxyHops } from './client-ip';

/** CORS de los endpoints OAuth públicos: cualquier origen y sin credenciales (no se usan cookies). */
export const CORS_HEADERS: Record<string, string> = {
  'Access-Control-Allow-Origin': '*',
  'Access-Control-Allow-Methods': 'GET, POST, OPTIONS',
  'Access-Control-Allow-Headers': 'Authorization, Content-Type, MCP-Protocol-Version',
  'Access-Control-Max-Age': '86400',
};

const NO_STORE: Record<string, string> = { 'Cache-Control': 'no-store', Pragma: 'no-cache' };
const MAX_BODY_CHARS = 10_000;

export function preflight(): Response {
  return new Response(null, { status: 204, headers: CORS_HEADERS });
}

/** JSON con CORS y sin caché (las respuestas de token nunca deben cachearse, RFC 6749 §5.1). */
export function json(data: unknown, status = 200): Response {
  return Response.json(data, { status, headers: { ...CORS_HEADERS, ...NO_STORE } });
}

export function oauthError(error: string, description: string, status = 400): Response {
  return json({ error, error_description: description }, status);
}

export function oauthErrorResponse(err: OAuthError): Response {
  return oauthError(err.code, err.message, err.code === 'invalid_client' ? 401 : 400);
}

/** IP del cliente detrás de los proxies de confianza (para limitar la frecuencia). */
export function requestIp(request: Request): string {
  return clientIpFrom(request.headers.get('x-forwarded-for'), trustedProxyHops());
}

/** Cuerpo como texto, o null si supera los 10 KB (los cuerpos OAuth legítimos son chicos). */
export async function readBody(request: Request): Promise<string | null> {
  const declared = Number(request.headers.get('content-length') ?? '0');
  if (declared > MAX_BODY_CHARS) return null;
  const text = await request.text();
  return text.length > MAX_BODY_CHARS ? null : text;
}

/** Formulario application/x-www-form-urlencoded (así llegan /token y /revoke), o null si el tipo o el tamaño no corresponden. */
export async function readForm(request: Request): Promise<URLSearchParams | null> {
  const type = request.headers.get('content-type')?.toLowerCase() ?? '';
  if (!type.startsWith('application/x-www-form-urlencoded')) return null;
  const text = await readBody(request);
  return text === null ? null : new URLSearchParams(text);
}

/** Valor de un parámetro; repetido o vacío cuenta como ausente (RFC 6749 §3.1). */
export function formParam(form: URLSearchParams, name: string): string | undefined {
  const values = form.getAll(name);
  return values.length === 1 && values[0] !== '' ? values[0] : undefined;
}
```

```ts
import { json, oauthError, oauthErrorResponse, preflight, readBody, requestIp } from '@/lib/oauth-http';
import { createRateLimiter } from '@/lib/rate-limit';

export const dynamic = 'force-dynamic';

// El registro no tiene autenticación (RFC 7591): se limita por IP. Cada conexión nueva de Claude registra un cliente.
const registerLimiter = createRateLimiter({ max: 20, windowMs: 60 * 60 * 1000 });

export function OPTIONS(): Response {
  return preflight();
}

export async function POST(request: Request): Promise<Response> {
  if (!registerLimiter.check(requestIp(request))) {
    return oauthError('invalid_request', 'Demasiados registros desde esta IP: probá más tarde', 429);
  }
  const text = await readBody(request);
  if (text === null) return oauthError('invalid_client_metadata', 'El cuerpo es demasiado grande', 413);
  let metadata: unknown;
  try {
    metadata = JSON.parse(text);

    return oauthError('invalid_client_metadata', 'El cuerpo debe ser JSON');
  }
  try {
    const client = await registerClient(await getDb(), metadata);

      client_id: client.clientId,

      client_name: client.clientName,

      response_types: ['code'],
      token_endpoint_auth_method: 'none',
```

```ts
import { OAuthError, exchangeAuthorizationCode, refreshAccessToken } from '@/core/oauth';
import { getDb } from '@/db';
import { mcpResourceUrl } from '@/lib/app-url';
import {
  formParam, json, oauthError, oauthErrorResponse, preflight, readForm, requestIp,
} from '@/lib/oauth-http';
import { createRateLimiter } from '@/lib/rate-limit';

export const dynamic = 'force-dynamic';

const tokenLimiter = createRateLimiter({ max: 60, windowMs: 60 * 1000 });

export function OPTIONS(): Response {
  return preflight();
}

export async function POST(request: Request): Promise<Response> {
  if (!tokenLimiter.check(requestIp(request))) {
    return oauthError('temporarily_unavailable', 'Demasiadas solicitudes: probá en un minuto', 429);
  }
  const form = await readForm(request);
  if (!form) return oauthError('invalid_request', 'El cuerpo debe ser application/x-www-form-urlencoded (máx. 10 KB)');
  const opts = { resource: mcpResourceUrl() };
  try {
    const grantType = formParam(form, 'grant_type');
    if (grantType === 'authorization_code') {
      return json(await exchangeAuthorizationCode(await getDb(), {
        code: formParam(form, 'code'),
        clientId: formParam(form, 'client_id'),
        redirectUri: formParam(form, 'redirect_uri'),
        codeVerifier: formParam(form, 'code_verifier'),
        resource: formParam(form, 'resource'),
      }, opts));
    }
    if (grantType === 'refresh_token') {
      return json(await refreshAccessToken(await getDb(), {
        refreshToken: formParam(form, 'refresh_token'),
        clientId: formParam(form, 'client_id'),
        resource: formParam(form, 'resource'),
      }, opts));
    }
    return oauthError('unsupported_grant_type', 'grant_type debe ser authorization_code o refresh_token');
  } catch (err) {
    if (err instanceof OAuthError) return oauthErrorResponse(err);
    // Los secretos se hashean antes de tocar la base: el error nunca incluye un token en claro.
    console.error('[oauth/token] error inesperado', err);
    return oauthError('server_error', 'Error interno', 500);
  }
}
```

```ts
'use server';

import { redirect } from 'next/navigation';
import {
  authorizationParamsFrom, buildRedirectUrl, createAuthorizationCode, validateAuthorizationRequest,
} from '@/core/oauth';
import { getDb } from '@/db';
import { appUrl, mcpResourceUrl } from '@/lib/app-url';
import { requireUser } from '@/lib/auth';

/** Revalida todo lo que viene del formulario de consentimiento y redirige al cliente. */
async function decide(form: FormData, approve: boolean): Promise<never> {
  const user = await requireUser();
  const db = await getDb();
  const params = authorizationParamsFrom((name) => {
    const values = form.getAll(name);
    return values.length === 1 && typeof values[0] === 'string' ? values[0] : undefined;
  });
  const check = await validateAuthorizationRequest(db, params, { resource: mcpResourceUrl() });
  if (!check.ok) {
    // La página ya validó lo mismo: llegar acá significa que el formulario fue manipulado.
    if (!check.redirect) throw new Error(check.error);
    redirect(buildRedirectUrl(check.redirectUri, {
      error: check.error, error_description: check.description, state: check.state, iss: appUrl(),
    }));
  }
  if (!approve) {
    redirect(buildRedirectUrl(check.redirectUri, {
      error: 'access_denied', error_description: 'El usuario no autorizó el acceso', state: check.state, iss: appUrl(),
    }));
  }
  const code = await createAuthorizationCode(db, {
    clientId: check.client.clientId, userId: user.id, redirectUri: check.redirectUri,
    codeChallenge: check.codeChallenge, scope: check.scope, resource: check.resource,
  });
  redirect(buildRedirectUrl(check.redirectUri, { code, state: check.state, iss: appUrl() }));
}

export async function approveAuthorizationAction(form: FormData): Promise<void> {
  await decide(form, true);
}

export async function denyAuthorizationAction(form: FormData): Promise<void> {
  await decide(form, false);
}
```

```ts
import { callTool, type ToolContext } from '@/mcp/tools';

/** Llama una herramienta y devuelve su JSON; falla si la herramienta devolvió error. */
export async function callOk(ctx: ToolContext, name: string, args: Record<string, unknown> = {}) {
  const result = await callTool(ctx, name, args);
  if (result.isError) throw new Error(`${name} devolvió error: ${result.content[0].text}`);
  // eslint-disable-next-line @typescript-eslint/no-explicit-any
  return JSON.parse(result.content[0].text) as any;
}

/** Llama una herramienta que debe fallar y devuelve el mensaje de error. */
export async function callError(ctx: ToolContext, name: string, args: Record<string, unknown> = {}): Promise<string> {
  const result = await callTool(ctx, name, args);
  if (!result.isError) throw new Error(`${name} debía fallar y devolvió: ${result.content[0].text}`);
  return result.content[0].text;
}
```

```ts
  name: string;

  description: string;

  name: string;
  title: string;
  description: string;

const TOOLS_BY_NAME = new Map(TOOLS.map((tool) => [tool.name, tool]));
const GENERIC_ERROR = 'Ocurrió un error inesperado en Notas. Probá de nuevo más tarde.';

function errorResult(message: string): ToolResult {
  return { content: [{ type: 'text', text: message }], isError: true };
}

/**
 * Ejecuta una herramienta: valida los argumentos y traduce los errores. Los de dominio (validación, no existe)
 * vuelven como `isError` con su mensaje para que la IA corrija; los inesperados, con un mensaje genérico.
 */
export async function callTool(ctx: ToolContext, name: string, args: unknown): Promise<ToolResult> {
  const tool = TOOLS_BY_NAME.get(name);
  if (!tool) return errorResult(`Herramienta desconocida: ${name}`);
  const parsed = tool.input.safeParse(args ?? {});
  if (!parsed.success) return errorResult(`Argumentos inválidos:\n${z.prettifyError(parsed.error)}`);
  try {
    const data = await tool.run(ctx, parsed.data);
    return { content: [{ type: 'text', text: JSON.stringify(data) }] };
  } catch (err) {
    if (err instanceof ValidationError || err instanceof NotFoundError) return errorResult(err.message);
    console.error(`[mcp] error inesperado en ${name}`, err);
    return errorResult(GENERIC_ERROR);
  }
}
```

```ts
export const MCP_URL = 'https://notas.test/mcp';

/** POST JSON-RPC a /mcp como lo hace un cliente de la era 2025. */
export function rpcRequest(
  token: string | undefined, id: number, method: string, params: Record<string, unknown> = {},
  headers: Record<string, string> = {},
): Request {
  const all: Record<string, string> = {
    'content-type': 'application/json',
    accept: 'application/json, text/event-stream',
    'mcp-protocol-version': '2025-06-18',
    ...headers,
  };
  if (token) all.authorization = `Bearer ${token}`;
  return new Request(MCP_URL, { method: 'POST', headers: all, body: JSON.stringify({ jsonrpc: '2.0', id, method, params }) });
}

/** Cuerpo JSON-RPC de una respuesta, venga como JSON o como SSE (`event: message` / `data: …`). */
export async function readRpc(response: Response) {
  const text = await response.text();
  let payload = text;
  if ((response.headers.get('content-type') ?? '').includes('text/event-stream')) {
    const data = text.split(/\r?\n/).filter((l) => l.startsWith('data:')).map((l) => l.slice(5).trim()).filter(Boolean);
    if (data.length === 0) throw new Error(`Respuesta SSE sin datos: ${text}`);
    payload = data[data.length - 1];
  }
  // eslint-disable-next-line @typescript-eslint/no-explicit-any
  return JSON.parse(payload) as any;
}

/** `fetch` para el cliente oficial del SDK que llama directo al route handler, con el token. */
export function fetchVia(handler: (request: Request) => Promise<Response>, token: string) {
  return (input: string | URL | Request, init?: RequestInit): Promise<Response> => {
    const request = new Request(input, init);
    request.headers.set('authorization', `Bearer ${token}`);
    return handler(request);
  };
}
```

```ts
import { getDb } from '@/db';
import { appUrl, mcpResourceUrl, protectedResourceMetadataUrl } from '@/lib/app-url';

import { createNotasMcpServer } from '@/mcp/server';

export const dynamic = 'force-dynamic';

/**
 * Sin estado: el SDK arma un McpServer nuevo por request con la factory (atado al usuario autenticado).
 * Atiende la era 2026-07-28 y, como fallback sin estado, la 2025 (initialize; GET/DELETE → 405).
 */
const mcpHandler = createMcpHandler(async ({ authInfo }) => {
  const userId = authInfo?.extra?.userId;
  if (typeof userId !== 'string') throw new Error('Solicitud MCP sin usuario autenticado');
  return createNotasMcpServer(await getDb(), userId);
}, {
  onerror: (err) => console.error('[mcp]', err.message),
});

const perUserLimiter = createRateLimiter({ max: 120, windowMs: 60 * 1000 });

/** 401 con el puntero a la metadata del recurso (RFC 9728 §5.1) y el scope (RFC 6750 §3). */
function unauthorized(invalidToken: boolean): Response {
  const params = [`resource_metadata="${protectedResourceMetadataUrl()}"`, `scope="${OAUTH_SCOPE}"`];
  if (invalidToken) params.push('error="invalid_token"', 'error_description="El token no es válido o venció"');
  return Response.json(
    { error: invalidToken ? 'invalid_token' : 'unauthorized', error_description: 'Falta un token Bearer válido' },
    { status: 401, headers: { 'WWW-Authenticate': `Bearer ${params.join(', ')}` } },
  );
}

function bearerToken(header: string | null): string | null {
  const match = header?.match(/^Bearer\s+(\S+)\s*$/i);
  return match ? match[1] : null;
}

async function handle(request: Request): Promise<Response> {
  // La spec pide validar Origin (DNS rebinding). Claude/ChatGPT llaman desde sus servidores, sin Origin.
  const origin = request.headers.get('origin');
  if (origin !== null && origin !== new URL(appUrl()).origin) {
    return Response.json({ error: 'Origen no permitido' }, { status: 403 });
  }
  const token = bearerToken(request.headers.get('authorization'));
  if (!token) return unauthorized(false);
  const auth = await authenticateBearer(await getDb(), token, { resource: mcpResourceUrl() });
  if (!auth) return unauthorized(true);
  if (!perUserLimiter.check(auth.userId)) {
    return Response.json(
      { error: 'Demasiadas solicitudes: probá en un minuto' },
      { status: 429, headers: { 'Retry-After': '60' } },
    );
  }
  return mcpHandler.fetch(request, {
    // El SDK no necesita el token: nunca lo pasamos para que no pueda terminar en un log.
    authInfo: {
      token: 'redacted',
      clientId: auth.via === 'oauth' ? auth.clientId : 'personal',
      scopes: [OAUTH_SCOPE],
      extra: { userId: auth.userId },
    },
  });
}

export const GET = handle;
export const POST = handle;
export const DELETE = handle;
```

```ts
    content?: { type: string; text: string }[];
    isError?: boolean;
  };

/** Cuerpo JSON-RPC, venga como JSON o como SSE (`data: …`). */
function parseRpc(text: string, contentType: string): RpcResponse {
  if (!contentType.includes('text/event-stream')) return JSON.parse(text) as RpcResponse;
  const data = text.split(/\r?\n/).filter((l) => l.startsWith('data:')).map((l) => l.slice(5).trim()).filter(Boolean);
  return JSON.parse(data[data.length - 1]) as RpcResponse;
}

export function rpcBody(id: number, method: string, params: Record<string, unknown> = {}) {
  return { jsonrpc: '2.0', id, method, params };
}

/** POST a /mcp con el token; falla si la respuesta HTTP no es 200. */
export async function mcpCall(
  request: APIRequestContext, token: string, id: number, method: string, params: Record<string, unknown> = {},
): Promise<RpcResponse> {
  const res = await request.post('/mcp', {
    headers: { ...MCP_HEADERS, authorization: `Bearer ${token}` }, data: rpcBody(id, method, params),
  });
  if (res.status() !== 200) throw new Error(`/mcp respondió ${res.status()}: ${await res.text()}`);
  return parseRpc(await res.text(), res.headers()['content-type'] ?? '');
}

/** Status HTTP de un tools/list con ese token (para comprobar revocaciones). */
export async function mcpStatus(request: APIRequestContext, token: string): Promise<number> {
  const res = await request.post('/mcp', {
    headers: { ...MCP_HEADERS, authorization: `Bearer ${token}` }, data: rpcBody(99, 'tools/list'),
  });
  return res.status();
}

/** JSON devuelto por una herramienta (falla si fue un error). */
export function toolJson(response: RpcResponse): unknown {
  const text = response.result?.content?.[0]?.text;
  if (response.result?.isError || text === undefined) throw new Error(`La herramienta falló: ${JSON.stringify(response)}`);
  return JSON.parse(text);
}
```

```ts
  expect(await reused.json()).toMatchObject({ error: 'invalid_grant' });
```

## Riesgos y pendientes

1. **DCR quedó "deprecated" en la spec 2026-07-28** (lo recomendado es CIMD). Claude y ChatGPT lo siguen soportando por defecto y caen a DCR si el AS no anuncia CIMD. Si algún cliente deja de usar DCR, agregar CIMD (descargar y cachear la metadata del `client_id` URL con protección SSRF).
2. **SDK v2 muy nuevo** (2.3.1 publicada el 2026-10-05; la API difiere de los ejemplos de v1 que abundan en internet). Versión exacta fijada; verificar el changelog antes de actualizar.
3. **Rotación estricta del refresh:** dos refresh simultáneos con el mismo token revocan la familia y el cliente debe reconectarse. Si pasa en la práctica, agregar un período de gracia corto para el token recién rotado.
4. **Límites de frecuencia en memoria:** valen con una sola instancia (igual que el login); el Plan 5 despliega una réplica.
5. **Origin en `/mcp`:** bloquea clientes MCP que corren en el navegador (p. ej. el MCP Inspector web) contra producción. Para depurar, usar el Inspector local o un token personal desde un script.
6. **Redirects con esquema propio** (p. ej. `cursor://…`) no se aceptan: Cursor y similares se conectan con token personal en el header `Authorization`.
7. **`resource` estricto:** solo se acepta `<APP_URL>/mcp` (con tolerancia de mayúsculas/barra final). Un cliente que mande solo el origen recibiría `invalid_target`; relajarlo es una línea en `checkResourceParam`/`validateAuthorizationRequest` si aparece.
8. **Registro dinámico sin autenticación:** limitado por IP y con limpieza de huérfanos (`purgeExpiredOAuthData`), que hay que programar en el cron del Plan 5.
9. **Nombre del cliente lo elige el cliente** (podría decir "Claude"): el consentimiento muestra además el host del redirect y advierte si es loopback.
10. **Proxy:** las respuestas de la era 2025 son SSE; Caddy no debe bufferearlas (por defecto no lo hace con `text/event-stream`).
